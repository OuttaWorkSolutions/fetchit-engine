Review before you send

A drop-in panel a developer mounts in their own app. It cleans AI-generated text, color-codes what changed and what still reads as AI, lets the person accept, reject, or edit, then hands back the final text. Everything runs in the browser; the text never leaves the page.

How a developer adds it

import { attachReview } from "@fetchitai/review";

attachReview(document.querySelector("#compose"), {
  text: aiDraft,
  onApply: (finalText) => sendEmail(finalText),
});

One import, one call. No API key, no network, no server. The same @fetchitai/engine that powers fetchitai.com runs locally inside the widget.
